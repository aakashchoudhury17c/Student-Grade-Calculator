
# Student Grade Calculator

Java project that calculates a student's total marks, percentage, and grade across five subjects.

## Features

- Accepts marks for five subjects
- Validates marks between 0 and 100
- Calculates total marks
- Calculates percentage
- Assigns a grade based on percentage

## Technologies Used

- Java
- JDK (Java Development Kit)

## For Running flawlessly

### 1.For Compiling the program

```bash
javac GradeCalculator.java
```

### 2. For Running the program

```bash
java GradeCalculator
```

## Example

If the marks are 80, 70, 90, 85, and 75:

- Total Marks: 400/500
- Percentage: 80%
- Grade: B
